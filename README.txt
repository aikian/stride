STRIDE 2.0 — 로그인 없는 독립형 러닝 웹앱

1. 실행하기
ZIP을 압축 해제한 뒤 index.html을 JavaScript를 지원하는 브라우저에서 여세요.
index.html 안에 화면, 스타일, 프로그램이 모두 들어 있습니다.
사용을 위해 npm 설치, 계정 가입, API 키, 서버 연결을 할 필요는 없습니다.
휴대폰의 '파일 미리보기'는 JavaScript 실행을 지원하지 않을 수 있습니다.
이 경우 브라우저로 열기 기능이 있는 환경이나 아래 HTTPS 실행을 사용하세요.
파일을 직접 열 수 있는지는 휴대폰 브라우저/파일 앱에 따라 다릅니다.

2. 날짜별 코스
하단 '날짜별 코스'에서 시작일을 정하면 8주 56일 일정이 만들어집니다.
시작일부터 매주 1·3·5일째가 훈련일이고 나머지는 휴식일입니다.
날짜를 누르면 준비 걷기, 달리기/걷기 5회, 마무리 걷기까지 구간별 시간이 나옵니다.
휴대폰에서는 선택한 날짜의 상세가 팝업으로 열립니다.
'이 날짜의 코스 선택' → '운동 시작'으로 해당 훈련을 실행합니다.
각 주의 3회차는 달리기 구간이 30초 늘어납니다.
신장/체중/경험을 바꾸면 이후 표시되는 추천 훈련도 바뀝니다.
과거 운동 기록에 저장된 구간은 그대로 남습니다.
여기서 코스는 날짜별 훈련 순서이며, 특정 도로의 지도 경로를 추천하지는 않습니다.

3. 구간 넘기기
'다음 구간'은 준비 걷기에서 달리기로, 달리기에서 휴식으로 즉시 이동합니다.
일시정지 상태에서는 다음 구간으로 이동해도 일시정지가 유지됩니다.
'전체 구간'에서 현재 구간과 남은 운동을 확인할 수 있습니다.
건너뛴 시간은 실제 운동 시간이나 칼로리에 더하지 않습니다.
마지막 구간에서 '마지막 구간 끝내기'를 누르면 기록을 저장합니다.
건너뛴 구간이 있는 기록에는 그 개수가 표시되며 '부분 운동'으로 기록됩니다.

4. 저장
프로필/시작일/기록은 이 브라우저에만 저장됩니다. 외부 서버 전송은 없습니다.
파일 위치 변경, 시크릿 모드 종료, 브라우저 데이터 삭제는 기록 손실을 일으킬 수 있습니다.
'내 정보 → 내 기록 내보내기'로 JSON 백업을 보관하세요.
저장 공간을 사용할 수 없으면 오류를 표시합니다.

5. GPS 및 설치
파일 직접 실행에서는 GPS를 사용하지 않고 구간 타이머/음성/기록을 제공합니다.
GPS와 홈 화면 설치를 사용하려면 이 폴더를 정적 호스팅에 올리고 HTTPS 주소로 열어야 합니다.
특정 호스팅 회사나 Vercel 계정은 필요하지 않습니다.
HTTPS에서는 위치 권한을 허용하면 GPS 거리/페이스가 측정됩니다.
manifest.webmanifest, sw.js, 아이콘 2개를 index.html과 함께 유지하세요.
HTTPS에서 첫 실행이 끝나면 서비스 워커가 앱을 저장하여 이후 오프라인 실행을 지원합니다.
브라우저/기기에 따라 홈 화면 설치 메뉴가 다를 수 있습니다.

6. 화면 잠금과 음성
웹앱은 화면이 꺼졌을 때 GPS/음성의 지속 실행을 보장할 수 없습니다.
정확하지 않은 기록을 만들지 않도록 화면이 숨겨지면 자동 일시정지합니다.
지원하는 브라우저에서는 운동 중 화면 켜짐 유지를 요청합니다.
한국어 음성은 기기에 설치된 TTS 음성을 사용하며 없으면 기본 음성으로 재생됩니다.
실제 휴대폰의 GPS/음성/설치는 별도의 현장 확인이 필요합니다.

7. 개발자가 수정하기
완성된 index.html을 이용할 때는 설치가 필요 없습니다.
소스를 수정할 때만 Node.js 환경에서 npm install → npm run check → npm test → npm run build를 실행하세요.
src/App.tsx: 앱과 훈련/기록 동작
src/base.css, src/extra.css: 화면 스타일
build.mjs: 모든 코드와 스타일을 index.html 하나로 묶는 빌드
서버 없이 사용하려고 만든 앱이므로 로그인/API/데이터베이스 설정은 없습니다.
